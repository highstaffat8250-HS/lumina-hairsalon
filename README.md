# LUMINA — Hair Salon Portfolio Site

架空の美容室「LUMINA」をテーマにした、Web制作ポートフォリオ用の7ページサイトです。

## Pages
- index.html — TOP
- concept.html — CONCEPT
- menu.html — MENU
- staff.html — STAFF
- gallery.html — GALLERY
- news.html — NEWS
- access.html — ACCESS

## Features
- Responsive design
- Custom reset CSS
- Intersection Observer scroll reveal
- Mobile navigation
- Header scroll state
- Editorial / magazine-style layout
- Hover micro-interactions
- OG metadata / theme color
